# Session 2026-07-19c (later same day) — the tail handoff lands (item 3b), and production turns out to have always run fixed-RK4

Numbers and why-chains in measurements.md 2026-07-19c. Three jj changes:
k1 reuse + the discovery, the handoff, wrap.

- **The k1-reuse rider went first** (bit-identical CSE from the morning
  addenda): dopri_step takes k1 and returns the FSAL k7; both twin loops
  carry k1 across rejects and reuse k7 on no-hop accepts. The no-hop test
  is componentwise scalar egal (`same_phase`) — first attempt used
  whole-struct `===`, which lowers to a memcmp runtime call the device
  compiler rejects. Certified bit-identical (451 cold, physics_diff
  exactly 0/0, parity counts in character).
- **Every A/B read neutral, and the why is the session's discovery**:
  production RayBudgets are all the 3-arg constructor — tolerance 0.0 —
  so trace_ray/sweep_ray take the fixed-step RK4 branch everywhere and
  dopri executes only in tests. Corrections recorded: the 19b census's
  "7 × flow6 per attempt" counted the wrong branch's call graph (the
  shared-tower conclusions and all landed wins survive; per-attempt stage
  count is 4); item 3(e) inverts — the cheap integrator is the status
  quo, dopri-with-tolerance is the untaken expensive path, and the live
  question is whether error control buys accuracy worth its cost
  (Richardson probe judges). k1 reuse kept: footprint-only cost, makes
  the dopri arm fair for (e).
- **Round census priced the tail**: rounds 3–7 of the 768×576 static
  probe are a ~33 ms/round latency floor for ≤616 rays (37% of kernel);
  round 2 (3649 rays, 33 ms) is still throughput-efficient on device.
- **The handoff** (item 3b): DeviceSweep.handoff — rounds with ≤ handoff
  active records run threaded_sweep! to completion at the sweep_stage!
  seam. Defaults threads=128, handoff=1024; flyvideo gpu=1 inherits.
  Certified: handoff > poolsize is bit-identical to the CPU wavefront
  (diff 0 both precisions), parity 0 flips, hybrid-vs-pure moves 0.8%
  straggler-class pixels, renders eyeball-identical.
- **Outcome**: static probe wall −20% (0.500 → 0.401); mid-crossing
  neutral *correctly* (single 442k-ray round — no tail to hand off;
  measured by coasting the cube flight to d=0.38 and benching the
  SituatedCamera raymap); 192×144 device F32 0.18 → 0.051 wall, now
